# As Aventuras dos Insetos — atualizações

Este repositório guarda só as versões publicadas do jogo **As Aventuras dos Insetos** (Cerne Software):

- `manifesto.json`: a versão mais nova, lida pelo jogo para avisar que há atualização (servido pelo GitHub Pages).
- **Releases**: o APK para Android e o instalador para Windows de cada versão, com o SHA-256 de cada arquivo no manifesto.

O código do jogo não fica aqui.
